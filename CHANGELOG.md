# Changelog

## [1.6.0] - 2026-10-18

- Real accounts: `POST /api/auth/signup`, `/login`, `/logout` and
  `GET /api/auth/me`. Passwords are hashed with bcrypt (12 rounds) and the
  session is a 7-day JWT in an httpOnly cookie. Login and signup are limited
  to 20 attempts per 15 minutes per IP
- Alumni directory reads the API: `GET /api/users?q=` (members only, emails
  never returned) replaces `GET /users/all`, and the search box queries it as
  you type with `?q=` kept in the URL
- `npm run seed` loads 10 sample alumni and a demo account from
  `client/src/data/alumni.json`; the `User` schema gains email, password hash,
  company, designation, location and LinkedIn, and `Batch` is now `batch`
- Demo mode (`vite --mode demo`): the GitHub Pages build runs on the same
  bundled data with a tab-scoped session, so the live site works without a
  backend. Setting the `VITE_API_URL` repository variable switches it to the
  real API
- Member routes redirect to login when signed out and return to the page
  afterwards; the router is built once per sign-in or sign-out instead of on
  every render
- Move the client from Create React App 5 to Vite 8 and from
  `react-router-dom` 7 to `react-router` 8. Client `npm audit` goes from 53
  advisories to 0, installed packages from 1,354 to 134, and a production
  build from about 16 s to under 2 s; `--legacy-peer-deps` and the CRA override block
  are gone
- Server: CORS allowlist from `CLIENT_ORIGIN` with credentials, 100 kB JSON
  limit (was 30 MB), JSON error responses, `/api/health`, no artificial 1 s
  delay, and the app split into `app.js`, `auth.js` and `routes/`. `nodemon`
  is replaced by `node --watch`, which clears the server's 3 high advisories
- Replace the hotlinked stock logo with an owned SVG logo and favicon, and add
  Open Graph and Twitter card tags with a generated 1200x630 `og.png`
- README screenshots (desktop, phone, dark mode) generated by
  `npm run screenshots`, a Render blueprint with a Deploy button, and an
  updated architecture diagram and API table
- Fix alumni cards overflowing their fixed height and the auth card
  overflowing phone screens

## [1.5.0] - 2026-10-18

- Fix server startup: Mongoose 9 rejects the `useNewUrlParser` and
  `useUnifiedTopology` options, so the server failed with `MongoParseError` and
  never listened
- Serve `/users/all` with `app.get` instead of `app.use`, so other methods
  return 404
- Rate limit `/users/all` to 60 requests per minute per IP with
  `express-rate-limit` (CodeQL `js/missing-rate-limiting`)
- Patch critical shell-quote advisory GHSA-pqg4-j6r4-53mv by raising the
  override to `>=1.11.0` in root and client
- Refresh server and root dependencies within their ranges (Express 5.3,
  Mongoose 9.11, dotenv 18.0.8, concurrently 10.0.6, Prettier 3.9)
- Deploy the client to GitHub Pages from `main` with a `basename`-aware router
  and an SPA 404 fallback
- Make the layout mobile friendly: top nav wraps, side nav becomes a bottom tab
  bar, sections and the profile page no longer overflow at 375px
- Fix the wrong LinkedIn link on the contact card, the missing list `key`, and
  the empty "School" field on the profile page
- CI: least-privilege `permissions: contents: read` and `npm ci --ignore-scripts`
- Docs: correct README license (GPL-3.0), stack versions and target branch, add
  project status, architecture diagram, live demo link, the `server/.env`
  variables, and a real CONTRIBUTING guide
